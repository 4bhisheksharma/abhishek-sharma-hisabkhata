# Hisab Khata

A modern **digital credit and transaction management system** designed for small businesses in Nepal.

Hisab Khata replaces traditional paper-based bookkeeping with a **mobile-first solution** that enables businesses to manage credit, track transactions, and accept digital payments efficiently.

---

## Features

### Authentication & User Roles
- Secure login & registration with OTP verification  
- Role-based access: **Business / Customer / Admin / Hybrid**

### Transaction Management
- Record **normal and credit transactions**
- Automatic due calculation  
- Transaction history with search & filters  

### Digital Payments
- Integration with **eSewa** and **Khalti**
- Real-time payment status updates  

### Dashboard & Analytics
- Business insights (due, paid, trends)  
- Customer-level analytics  
- Visual charts for better decision making  

### Real-Time Communication
- In-app chat between business and customers  
- Instant notifications and reminders  

### Reports & Export
- Generate and download **PDF reports**  
- Monthly statements and summaries  

### Smart Features
- OCR-based **receipt scanning**  
- Voice-based transaction entry  
- AI chatbot for assistance  

### Admin Panel
- User management  
- Support ticket handling  
- Broadcast notifications  
- Platform monitoring
